# Yutnori – Three Player Web Game

A polished browser-based version of the traditional Korean board game **Yutnori**, designed for three players.

## Live Demo

```text
[https://keyacse.github.io/yutnori/]
```

## Features

- Three-player Yutnori gameplay
- Blue, Red, and Green teams
- Default team photos included
- Visitors can upload their own three team photos from Settings
- Custom team names
- English, Bengali, and Korean language support
- Yut stick throwing animation
- Suggested moves and hints
- Finished-piece display
- Final ranking for 1st, 2nd, and 3rd place
- Sound effects
- Optional Back Do rule
- Responsive interface
- GitHub Pages ready

## Main Files

- `index.html` — Main game file used for deployment
- `assets/` — Default team photos and game resources
- `.nojekyll` — Prevents GitHub Pages from processing the site with Jekyll
- `index.backup.html` — Backup version
- `index.pre_latest_changes.html` — Earlier version kept for recovery

## Run Locally

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The game will open in a browser.

No server installation is required.

## Custom Team Photos

The deployed game shows the three default team photos first. A visitor can open **Settings** and choose exactly three images in this order:

1. Blue Team
2. Red Team
3. Green Team

The selected images are stored only in that visitor's browser. They do not replace the original default images in the GitHub repository.
